Copy vault to another FIDO2 key

  1. Insert the target key. You can unplug the current one — the vault stays open in memory.
  2. Pick it below. Two keys look alike? Use Touch to pick.
  3. Enter the target key's PIN and press Copy to key.
  4. The target key blinks twice: touch it each time (on a fingerprint key, touch the sensor). The first touch creates the vault credential, the second unlocks that key's hmac-secret. Then the vault is written — don't unplug it until the dialog closes.

Your entries are re-encrypted with the target key's own hmac-secret, so each key can open its copy on its own.
